Troubleshooting LaTeX Compilation Errors:
------------------------------------------
If compilation fails:

1. Missing Figures:
   Error: "File 'figs/xyz.png' not found"
   Solution: Verify figure exists in figs/ folder, check filename spelling

2. Missing Packages:
   Error: "! LaTeX Error: File 'xyz.sty' not found"
   Solution: Install missing package via TeX package manager (tlmgr)

3. Syntax Errors:
   Error: Various LaTeX syntax errors
   Solution: Check .log file for line numbers, review .tex file syntax

4. Bibliography Errors:
   Error: Citation warnings or missing references
   Solution: Ensure .bib file exists, run bibtex, recompile

5. Figure Compilation Issues:
   Error: Figures not displaying correctly
   Solution: Check PNG file integrity, verify \includegraphics syntax
